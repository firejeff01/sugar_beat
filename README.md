# 糖豆衝衝 · Sugar Beat

以 Three.js 製作的原創糖豆障礙競速遊戲。輸入名字，與 11 位本機 AI 連續挑戰三關；每輪從 **36 張具名極難地圖**不重複抽三張，並重新生成機關配置與場外怪物事件。

**[立即遊玩](https://firejeff01.github.io/sugar_beat/)**

## 操作

| 按鍵 | 動作 |
| --- | --- |
| W / A / S / D | 前 / 左 / 後 / 右 |
| 空白鍵 | 跳躍，放開後可再次跳 |
| 左 Shift 或右 Shift | 前撲，冷卻 1.15 秒 |
| 按住 E + 方向鍵 | 抓住附近對手並拖拉，放開 E 鬆手 |
| 被抓住時按左／右 Shift | 前撲掙脫（前撲必須已冷卻） |
| Esc | 暫停 / 繼續 |

**手機與平板操作**：直接用瀏覽器開啟上方遊玩連結，不需安裝。左下虛擬搖桿可向任意方向拖動，右下有「跳躍」、「前撲」及「抓拉」按鈕。支援多指同時操作：一邊移動一邊跳躍／前撲，或按住「抓拉」再拖動搖桿拉走對手；被抓住時點「前撲」掙脫。跳躍要放開按鈕後才能再次觸發，按鈕內會顯示冷卻時間。

直向、橫向與平板均可遊玩；橫放手機能看見更寬的賽道。介面會避開螢幕安全區，轉向、取消觸控或暫停時會清除按住的操作，切換視窗會自動暫停。右上角可開啟音效與暫停；即使另一根手指仍在推搖桿，也可以點暫停。手機會採用較低的渲染解析度與陰影尺寸，減少繪圖負擔。需要支援 WebGL 的現代瀏覽器。

## 三關賽制

1. **極難起跑**：12 段賽道、窄橋雙機關、隨機怪物襲擊，80 秒。
2. **怪獸追擊**：13 段賽道，平台更窄、機關更快、怪物預警縮短，90 秒。
3. **地獄決勝**：14 段賽道、更大間隙，怪物出現更頻繁，100 秒。

36 張地圖由六個區域（焦糖煉獄、極凍糖谷、逆流工廠、斷橋深淵、空心迷城、漂浮禁區）與六種考驗（撞柱暴走、旋刃絞盤、拳柱伏擊、封路惡夢、巨槌審判、狂風裂隙）組成。每張有唯一編號、名稱及地形／機關配置；比賽左上角顯示目前地圖編號。第一關起就採用極難配置，之後繼續增加壓力。

地形與機關組合每輪重新洗牌。冰面降低摩擦、輸送帶向後與側面推動角色，雙線路中間是真的洞；漂移平台會帶著角色移動。挖空路兩側都有可通行路線，移動平台的重生點設在前一座穩定平台。

所有選手都參加三關。各關結算後按「前往下一關」繼續，本關被淘汰的選手也會重新上場。跌落會回到最近的平台重生點；碰撞會被擊退。AI 使用與玩家相同的移動、重力、碰撞及重生模擬，自行選路與跳躍。

**限時檢查門**：每張地圖在賽道約四分之一、二分之一、四分之三的位置設有三道門，實際位置配合平台生成，漂移平台上的門會一起移動。三道門各自有通過期限，均從起跑顯示 **GO** 時開始計時，通過前一門不會重設後一門的倒數；起跑前倒數及暫停期間不計時。畫面會顯示下一道門的剩餘時間，最後 10 秒加強警告。

玩家與 AI 必須依序從門內向前通過；繞到賽道外、從下方墜落經過或重生跳過門，都不算通過。已通過的紀錄會保留，跌落重生不必重跑已通過的門。期限到仍未通過就**立即淘汰並鎖定本關名次**，停止移動、碰撞及抓拉，玩家可觀戰剩餘選手直到本關結束，再參加下一關。

淘汰者排在仍在比賽及已完賽選手之後；越晚被淘汰，名次越前。同一時間被淘汰時，依當下賽道進度排序，再同進度依選手編號排序。鎖定後不會因其他選手後退或跌落改變名次。通過三門並抵達終點才算完賽。

角色之間可以互相干擾：迎面碰撞會減速與彈開，追撞會把前方角色推走，側撞會改變方向，也可能把對手擠出平台。前撲速度更快，撞擊推力更大；撞上後會結束前撲，並短暫降低轉向控制以保留慣性。玩家與 AI 使用相同的等質量碰撞規則。跳得夠高可以越過其他角色，已完賽或淘汰的角色不會阻擋其他選手。

**抓拉規則**：按住 E 抓住 2.05 單位內最近的可抓對手，最多持續 0.85 秒，再用方向鍵拖走他。抓人者與被抓者都會減速；鬆手後冷卻 2.5 秒，對手獲得 1.25 秒防連抓保護。按 Shift 可掙脫（前撲冷卻中或被機關擊暈時不能掙脫）；跳躍、前撲、跌落、距離過遠、完賽或淘汰也會讓抓人者鬆手。AI 會伺機抓拉、向邊緣拖人，也會使用前撲掙脫。畫面中的金色連線表示抓拉對象，狀態列顯示抓拉時間、冷卻及被抓提示。

## 場外怪物事件

每張地圖都有大怪物從賽道外現身，地面先標示攻擊區域，再朝賽道噴射。四種攻擊以隨機順序輪替，位置與出現時間也會改變。玩家與 AI 使用相同命中範圍與效果；預警本身不會造成傷害。

**利用地形躲怪物**：36 張地圖的每段平台都有實體威化牆，怪物會瞄準有掩體的區段。看清怪物從哪一側出現，再躲到牆背面的綠色安全區；威化牆能擋住火、水、冰與閃電。迎向怪物的牆面無法保護你，身體露出牆邊、跳得高過掩體，或被對手撞出／拉出遮蔽都會遭到攻擊。漂移平台上的牆與安全位置會隨平台移動。AI 也會尋找掩體，可能和你搶同一個躲藏位置；離開整片攻擊區域同樣能避開攻擊。

遮蔽依角色當下的位置持續判定：躲回牆後會停止水砲持續施加的推力，但不會抹除先前的慣性，也不會解除已經命中的燒焦、冰凍或雷擊反轉。

| 攻擊 | 命中效果 |
| --- | --- |
| 熔糖吐息 | 燒焦變黑 3.5 秒、冒煙；其中 2.5 秒移動減速 |
| 巨浪水砲 | 側向強力衝擊，可直接沖下賽道 |
| 冰封龍息 | 包覆冰塊，冰凍 1.8 秒，無法移動、跳躍、前撲或抓拉；仍會受外力推動 |
| 反轉雷暴 | 麻痺 0.65 秒；結束後操作反轉 **完整 5 秒** |

雷擊反轉期間：**W／S 互換、A／D 互換、空白鍵變後撲、Shift 變跳躍、E 抓拉變推開**。鍵盤與手機觸控套用相同規則，暫停與音效按鈕維持正常。HUD 顯示剩餘時間與反轉對照；暫停時倒數停止，跌落重生不會提前解除雷擊反轉，下一關會清除狀態。

手機遭雷擊後搖桿方向相反，原本的跳躍按鈕改為「後撲」、前撲按鈕改為「跳躍」、抓拉改為「推開」；按鈕文字同步顯示目前效果，反轉結束後恢復。

每關依名次給予 120、110、100……10 基分，三關倍率分別為 1、1.5、2。完賽者依抵達順序排名；總時間到仍在比賽者依目前進度排在完賽者之後，檢查門淘汰者維持已鎖定的名次。兩種未完賽情況均得分減半並四捨五入，各關結束只結算一次。最終依三關總積分排名，同分依總用時較短者優先（未完賽計該關時限，提早淘汰不會獲得時間優勢），再同分則依選手編號排序。每位選手都有逐關分數及總排名，結算表標示淘汰門號。

## 本機開發

需要 Node.js 22.12+（或 24+）。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`src/game.js` 為固定步長物理、AI、36 張地圖庫與計分模組。`src/timed-gates.js` 管理檢查門生成、實際穿門判定、到期淘汰與名次鎖定。`src/cover.js` 管理實體掩體、射線遮蔽及安全站位；`src/monster.js` 管理可重現的隨機事件、命中效果與輸入反轉；`src/monster-view.js` 負責 Three.js 大怪物、吐息與角色狀態特效，`src/main.js` 串接場景及介面。測試逐張涵蓋 36 張極難地圖、432 位模擬選手及怪物事件，並驗證地形連通性、碰撞、抓拉、雙向掩體、露身命中、狀態時間、雷擊反轉與限時淘汰。全圖都屬高難度，允許選手逾時或淘汰，仍會取得分數及排名。

推送至 `main` 後，GitHub Actions 自動測試、編譯及部署至 GitHub Pages。所有 JavaScript（包括 Three.js）都打包於網站，不需遊戲後端。Google Fonts 無法連線時使用系統字型。名字只存在本機瀏覽器。

`src/touch-controls.js` 將各根手指的搖桿／動作輸入分開管理，`src/mobile.css` 負責手機、橫向與平板版面。`npm run test:e2e` 包含 Chrome 手機模式下的多指觸控、取消操作、暫停、抓拉／掙脫、雷擊反轉及螢幕轉向測試，也涵蓋實際走過限時門、淘汰後操作停用與名次／積分、下一關復活、暫停倒數及手機計時介面。

本作是原創的障礙競速小遊戲，未使用 Fall Guys 的商標圖像或遊戲資產，也不是官方遊戲。玩法靈感參考 [Fall Guys 官方介紹](https://www.fallguys.com/about)。
